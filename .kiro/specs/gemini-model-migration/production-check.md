# 本番での確認の手順（gemini-model-migration）

> 作成：2026-11-16（タスク 4.3）
> `main` に入れて本番に出たあと、作者が本番 URL（https://time-schedule-app-two.vercel.app）で行う。開いている本番のタブは閉じて開き直してから始める。
> **2026-12-01 より前に**確かめる。12/1 までなら、おかしかったときに前の版（`gemini-2.5-flash`）に戻せる。

この spec では AI のモデルと、AI を呼ぶ部品だけを入れかえた。**画面の見た目と操作は変わらない**。確かめるのは、AI の返答の「形」と「口調」が今までどおりかどうか。

試しの画面（`npm run check:ui`）は AI の返答を偽物に差しかえて動くので、本物の新しいモデルの返答は、ここで初めて確かめる。

## 1. 相談（画面4）
1. 科目選択（画面3）で科目を3つほど選び、AI 相談に進む
2. 次を確かめる
   - 全体の講評が出る（約150文字。極端に短い・長いものになっていない）
   - 選んだ科目ごとにコメントが出て、科目の名前が合っている
   - コマどり先輩の口調（口は悪い・ツンデレ・熱血風だが、中身は具体的で実用的）
   - 将来の夢（プロフィールの職業）に触れている

## 2. 時間割の生成（画面5）
1. 科目選択で、どれか1つの科目のクラスをピン留めしてから、時間割の生成に進む
2. 次を確かめる
   - 5つのパターン（AIおすすめ・休日最大化・朝限回避・遅い時間回避・空きコマ削減）が出る
   - パターンごとの説明が短い定型文になっている
   - ピン留めしたクラスが、5つのパターンすべてで選ばれている
   - パターンを切りかえても、時間割が表示される

## 3. 成績のリアクション（画面7）
1. ダッシュボードから成績入力に進み、いくつか成績を選んで「コマどり先輩に評価してもらう」を押す
2. 次を確かめる
   - 称号（『〇〇』のような一言）と、評価とアドバイスが一続きになったセリフが出る（約150文字）
   - GPA によって態度が変わる（3.5 以上なら褒め気味、2.0 未満なら厳しめ）。余裕があれば、成績を変えて2回試す
   - コマどり先輩の口調

## 4. よくあること（不合格にしなくてよいもの）
- 「今は相談が殺到してて手が回らねえ。少し待ってからもう一回来い」が出る：Gemini の無料の枠が混んでいるとき。時間をおいてもう一度試して、AI の返答が出れば問題ない
- 返答の言い回しが前と少し違う：モデルが変わったため。口調と形が保たれていれば問題ない

## 5. 知らせてほしいこと
次のどれかがあれば、**どの画面で、どんな返答だったか**（画面のスクリーンショットか、文章のコピー）を教えてください。
- 口調がコマどり先輩らしくない（丁寧すぎる・キャラが崩れている）
- 文字数が極端に違う（数十文字しかない、何百文字もある）
- 何度試しても「なんか調子が悪いみてえだ。時間をおいて出直してこい」が出る
- 科目の名前やクラスが、選んだものと合っていない

口調や文字数が崩れていた場合は、作者の確認のうえで、AI への指示（プロンプト）を調整して出し直す。
