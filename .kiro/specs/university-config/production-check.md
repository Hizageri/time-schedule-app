# 本番での確認の手順（university-config）

> 作成：2026-11-27（タスク 4.4）
> `main` に入れて本番に出たあと、作者が本番 URL（https://time-schedule-app-two.vercel.app）で行う。開いている本番のタブは閉じて開き直してから始める。

この spec では、大学ごとに違う値を「大学ごとの設定」にまとめ、科目の条件を「共通の形」にした。会津大学の利用者から見て変わるのは、次の3つだけ。それ以外は今までどおりかを確かめる。

1. 成績の段階が会津大学の実際のもの（A・B・C・F。D なし）になった
2. 作者のシラバスとの見比べで、科目の条件を直した（開講時期の表示が変わった科目、消した科目・足した科目がある）
3. 前期・後期のどちらかで受ける科目が、前期と後期の両方の一覧に出るようになった

## 1. 共通の確認（流れの確認）

`roadmap.md` の「共通の確認」の 1〜6 を、**新しいアカウント**と**使ったことのあるアカウント**の2つで行う。

| # | 段階 | 確認すること |
|---|------|--------------|
| 1 | ログイン | Google でログインできる。新しいアカウントはオンボーディング、使ったことのあるアカウントはダッシュボードに進む。保存した時間割が初期値に戻っていない |
| 2 | 条件・科目選択 | 学年は **1〜4年**（6年までだったのを 4年までにした）、ベースクラスは 1〜2年が C1〜C6、3〜4年が CS・IT-SPR・SY・CN・IT-CMV・SE-DE。1〜4年が対象の科目の対象は「全学年」と出る。学年・学期を選ぶと合う科目だけが出る。詳細モーダル・ピン留め・選んだ単位数 |
| 3 | AI 相談 | 全体講評と科目ごとのコメントが出る。スキップして進める |
| 4 | 時間割作成 | 5パターンが出る。Q 切替、重なりの赤表示、クラスの手動変更、一時退避。確定するとダッシュボードに時間割が出る |
| 5 | 成績入力 | 成績を入れるとコマどり先輩の反応が出る。GPA が合う。「新学期へ進む」で学期（と学年）が進み、条件に戻る |
| 6 | 保存 | どの段階でもリロードして、状態（時間割・成績・ピン）が保たれている |

## 2. 成績の段階（A・B・C・F）

1. 成績入力（画面7）で、成績の選択肢が **A (4 点)・B (3 点)・C (2 点)・F (0 点) だけ**で、D がない
2. ダッシュボードの「成績」タブで「GPAを計算する」を押すと、段階が A・B・C・F の4つだけ
3. ダッシュボードの「プロフィール」タブで、成績評価システムが「A, B, C, F」、大学が「会津大学 (変更不可)」、学期制が「4学期制」
4. 前に D を入れたことのあるアカウントがあれば、その科目の成績入力の欄に **F** が出る。GPA は今までと同じ（D も F も 0 ポイント）

## 3. 科目の一覧と開講時期（見比べで直した科目）

科目選択（画面3）で、学年と学期を変えながら確かめる。

| 学年・学期 | 確かめること |
|---|---|
| 1年・前期 | 「HS05 文学」の開講時期が **2Q集中**。「OT08 TOEIC準備コース(Level A)」が **前期・後期**。「OT03-017 アントレプレナーシップ育成プログラム」が **前期**。インターンシップの「国内A」「シリコンバレーA」が**出ない** |
| 1年・後期 | 「OT08 TOEIC準備コース(Level A)」が出て **前期・後期**。「OT03-021 CPUを創ってみよう」が出て **後期**、詳細でクラスが月曜枠・水曜枠・木曜枠の3つ |
| 2年・前期と 2年・後期 | 「OT02-1 ベンチャー体験工房 1」が、どちらの学期の一覧にも出て **前期・後期** |

時間割の生成（画面5）で、1年・後期に「MA02 線形代数 II(C3/C4)」を選んで C3/C4 のクラスにすると、**Q4** の時間割に出る（Q3 には出ない）。

## 4. よくあること（不合格にしなくてよいもの）
- 前に保存した時間割の中の、見比べで直した科目（線形代数 II(C3/C4) など）は、確定し直すまで前の条件のまま表示されることがある（保存データの形は `university-data-model` で移し替えるまで変えないため）
- 「今は相談が殺到してて手が回らねえ。少し待ってからもう一回来い」が出る：Gemini の無料の枠が混んでいるとき。時間をおいてもう一度試す
