# 本番での確認の手順（src-structure-migration）

> 作成：2026-10-30（タスク 5.2）
> `main` に入れて本番に出たあと、作者が本番 URL で行う。開いている本番のタブは閉じて開き直してから始める。
> この spec はファイルの場所を変えただけなので、**見た目も動きも今までと同じ**であれば合格。違うところがあれば、どの画面で何をしたときかを教えてください。

2つのアカウントで行う。

- **使ったことのあるアカウント**：時間割を確定済みのもの
- **新しいアカウント**：一度も使っていないもの（オンボーディングから始まる）

## 1. ログイン（共通の確認 1）
1. 「Google でつづける」→ アカウントの選択画面が出る
2. 使ったことのあるアカウント → ダッシュボード（6）が出る。時間割・成績・プロフィールが前回のまま
3. 新しいアカウント → オンボーディング（1）が出る
4. Google のポップアップを自分で閉じる → 何も文言が出ず、ログイン画面のまま

## 2. 新しいアカウントで最初から最後まで（共通の確認 2〜5）
1. オンボーディング：ニックネーム・将来の職業・最大時限を入れる。入学年月・卒業予定年月は入れても入れなくても進める（卒業予定を入学と同じか前にすると止まる）
2. 条件（2）：学年・学期を選ぶ → 科目選択（3）に合う科目だけが出る
3. 科目選択（3）：科目をクリックして詳細を開く（シラバス・口コミ・成績評価割合）→「閉じる」。ピン留めできる。選んだ単位数が合う
4. AI 相談（4）：全体講評と科目ごとのコメントが出る。チェックを外して「時間割を自動生成」に進める
5. 時間割作成（5）：5パターンが出る。Q の切り替え・クラスの手動変更・一時退避と戻しができる。ピン留めしたクラスが全パターンで守られている
6. 確定 → ダッシュボード（6）に時間割が出る。Q の切り替え・集中講義の欄・授業の削除ができる
7. 「成績を入力して次学期へ」→ 成績入力（7）：成績を選び「コマどり先輩に評価してもらう」→ 称号と文面が出る
8. ダッシュボードの「成績」タブ：GPA シミュレーターが今までどおり計算する
9. 「この学期を終了して新学期へ進む」→ 確認で OK → 条件（2）に戻り、学期（と学年）が進んでいる

## 3. 保存（共通の確認 6）
1. 上の途中のどこかで、3 秒以上待ってからリロード → 同じ画面・同じ状態（時間割・成績・ピン）
2. 3 秒以上待ってからログアウトし、もう一度ログイン → 状態が残っている

## 4. プロフィールの編集
1. ダッシュボードの「プロフィール」タブ →「編集する」
2. ニックネーム・最大時限・入学年月・卒業予定年月を変えて「保存する」→ 表示が変わる
3. 卒業予定を入学と同じ年月にして保存 → 「卒業予定は入学より後の年月にしてください」と出て保存されない

## 5. スマートフォン
1. スマートフォンでログインし、ダッシュボードの時間割と、時間割作成（5）の一覧が今までどおり表示される
