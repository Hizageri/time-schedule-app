## Atomic・batch write・transaction

batch write と transaction は、どちらも複数の書き込みを atomic（全部成功するか、全部失敗するか）に行うために用いる。batch write は書き込みの指示をひとまとめにして送信する。これは現在のデータを読まずに（無視して）書き込みをする。transaction は batch write とは違い、現在のデータを読み取り、その値をもとにして書き込む内容を決める。私がデータを読み取ってから書き込むまでの間に、ほかのユーザーや自分の別のタブがデータを書き換えていないかを、データベース側で監視している。書き換えられていたら読み取りからやり直すので安全である。

## SQL・コンジャンクション・SQL インジェクション

SQL というのはデータベースを操作するときの言語のことです。SQL コンジャンクションという言葉自体は存在しなく、コンジャンクション（conjunction）という言葉自体は論理積という意味である。例）学年は一年かつ埋めたいコマは月曜の3.4限。など複数の条件から情報を抽出したいときに使う。SQL インジェクションとは、アプリがユーザーの入力をそのまま SQL の命令に組み込んでいるときに、入力欄に SQL の一部を書いて、アプリの命令を書き換えてしまう攻撃のこと。命令の一部を無視させたり条件を足したりして、パスワードを知らなくても誰でもログインできたり、ほかの人のデータを抜き取ったり消したりできてしまう。
