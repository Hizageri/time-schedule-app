## Atomic・batch write・transaction

batch write と transaction は、どちらも複数の書き込みを atomic（全部成功するか、全部失敗するか）に行うために用いる。batch write は書き込みの指示をひとまとめにして送信する。これは現在のデータを読まずに（無視して）書き込みをする。transaction は batch write とは違い、現在のデータを読み取り、その値をもとにして書き込む内容を決める。私がデータを読み取ってから書き込むまでの間に、ほかのユーザーや自分の別のタブがデータを書き換えていないかを、データベース側で監視している。書き換えられていたら読み取りからやり直すので安全である。
