# ADR（Architecture Decision Records）

コマどりの設計・技術・アーキテクチャで、**なぜそれを選んだのか**と、**ほかの選択肢をなぜ選ばなかったのか**の記録。

- 今どうなっているかは `.kiro/steering/` に書く。ここには、そうなった理由を書く
- 1つの決定につき1ファイル。`0000-template.md` をコピーし、次の番号を振って `NNNN-題名.md` にする
- 決定を変えたときも古い ADR は消さない。状態を「取りやめ（ADR-NNNN に置きかえ）」にして、新しい ADR を書く

## 状態

| 状態 | 意味 |
|------|------|
| 提案 | 検討中。まだ決めていない |
| 採用 | 決めて、今そのとおりになっている |
| 取りやめ | 一度採用したが、やめた（置きかえた ADR があれば番号を書く） |
