# ADR-0025：試しの大学への切りかえを、開発サーバーだけにする

- 状態：採用
- 日付：2026-11-18

## 選択肢

- 試しの画面の中だけで差しかえる
- 開発サーバーでだけ環境変数で切りかえる
- 本番でも効く環境変数で切りかえる

## 決めたこと

開発サーバーでだけ環境変数で切りかえる。`import.meta.env.DEV` が `true`（`npm run dev`）で、かつ環境変数 `VITE_UNIVERSITY=test` を付けたときだけ、試しの大学にする。

## 選んだ理由

開発サーバーを実際に開きながらデバッグしていく形を取りたい、それでいて本番を壊すことなく安全に行いたい。この二つを満たす設計にしたかったから。
環境変数だけを見て切りかえる方法もあったが、それだと Vercel の環境変数をまちがえたときに本番に試しの大学が出てしまう。そこで、試しの大学に切りかえる条件を、Vite がコマンドに合わせて決めてくれる目印（`import.meta.env.DEV`）と、外から付ける環境変数の二重にすることで、環境変数をまちがえても本番の利用者に影響が出ないようにした（フェイルセーフ）。
