# ADR-0023：時間割の5つのパターンを、AI ではなくコードで組む

- 状態：採用
- 日付：2026-11-17

## 選択肢

- 戦略ごとにプロンプトで AI に時間割を作ってもらう（今の形）
- 戦略ごとにアルゴリズムを組んで、コードで時間割を作る

## 決めたこと

戦略ごとにアルゴリズムを組んで、コードで時間割を作る。

## 選んだ理由

AI にプロンプトを投げて時間割を作らせる際のデメリットとして、Gemini が混んでいるときは利用できなくなる。作るごとに毎回違う時間割が作成される。作成に時間がかかる。などがあげられる。対して戦略ごとにアルゴリズムを組んでコードをつくる場合は作成が速いし毎回出力結果が変化しない。このアプリに求めるバリューとして時間割作成のときに無駄な時間を生み出さずにとりたい科目を逃さず取れることだと思っています。
