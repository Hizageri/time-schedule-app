# ADR-0021：画面のスタイルに Tailwind CSS を使う

- 状態：採用
- 日付：2026-11-12

## 選択肢

- Tailwind CSS
- 素の CSS ／ CSS Modules
- CSS-in-JS（styled-components・Emotion など）
- UI のコンポーネントライブラリ（MUI・Mantine・Chakra UI など）
- shadcn/ui

## 決めたこと

Tailwind CSS。

## 選んだ理由

おすすめされたからです。使い続ける理由は今のところ特にないです。これからデザイン定義書を作ってその定義書通りに作れない場合は tailwind を変えていくつもりです。
