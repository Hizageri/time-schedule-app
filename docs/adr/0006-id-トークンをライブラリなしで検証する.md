# ADR-0006：Firebase ID トークンを、ライブラリを使わず公開鍵で検証する

- 状態：採用
- 日付：2026-10-23
- 関係する spec：`secure-and-stable`（要件 1）
- 出典：`.kiro/specs/secure-and-stable/research.md`「Firebase ID トークンの検証」「Architecture Pattern Evaluation」「Synthesis Outcomes」、`.kiro/steering/tech.md`

## 背景

AI 窓口（`api/*`）は誰でも呼べる状態だった。ログインしている利用者だけに使わせるため、ブラウザは Firebase の ID トークン（JWT）を `Authorization: Bearer` で送り、サーバーで検証することにした。検証の方法を決める必要があった。

## 選択肢

### 案A：`firebase-admin`（公式の Admin SDK）
- 概要：`verifyIdToken()` で検証する
- メリット：いちばん確実。トークンの取り消し（revocation）の確認もできる
- デメリット：大きい依存が増える。サービスアカウントの秘密鍵を管理する必要が増える

### 案B：Node.js 標準の `crypto` で JWT を検証
- 概要：Firebase の公式手順「Verify ID tokens using a third-party JWT library」どおりに、Google の公開鍵（x509）で RS256 の署名を検証し、`exp`・`iat`・`aud`・`iss`・`sub`・`auth_time` を確かめる。公開鍵は `Cache-Control` の `max-age` の間キャッシュする
- メリット：依存が増えない。秘密鍵が要らない（使うのは公開鍵とプロジェクト ID だけ）。キャッシュがあるので速い
- デメリット：確かめる項目を自分で漏れなく実装する必要がある

### 案C：Firebase Auth の REST API（`accounts:lookup`）に問い合わせる
- 概要：トークンを Firebase に送って、有効か聞く
- メリット：実装が短い
- デメリット：毎回外部に問い合わせるので遅い。検証の方法として公式に案内されていない

## 決めたこと

案B（`api/_lib/auth.ts`）。

## 選ばなかった理由

- 案A：新しい大きなライブラリと、サービスアカウントの秘密鍵の管理が増える。秘密情報が増えるほど漏えいのリスクも増える
- 案C：リクエストごとに外部 API への往復が増える。公式に案内された検証方法ではない

## 結果

- 良くなること：依存も秘密情報も増やさずに、ログインしている人だけに AI 窓口を使わせられる
- 受け入れたトレードオフ：JWT の検証だけでは、取り消されたトークンは分からない。このアプリでは取り消しの確認までは行わない（トークンの有効期限は1時間）
- リスクへの対応：公開鍵が取れないとき（Google 側の障害など）は 401 ではなく 503 を返し、利用者をログアウトさせない。テスト用の鍵で作ったトークンで、ヘッダーなし・壊れた形・アルゴリズム違い・知らない鍵 ID・署名の改ざん・期限切れ・別プロジェクトがそれぞれ通らないことを確かめた（secure-and-stable タスク 2.1）。知らない鍵 ID のための公開鍵の取り直しは 60 秒に1回までにした
- 見直す条件：取り消しの確認が必要になったとき（例：アカウントの停止機能を作るとき）

## 聞かれたときの答え方

> Q. なぜ `firebase-admin` を使わなかったのですか？

`firebase-admin` を使うと、サービスアカウントの秘密鍵をサーバーに置く必要があります。ID トークンの検証だけなら、Firebase の公式手順どおりに Google の公開鍵で RS256 の署名と各クレームを確かめれば足りるので、Node.js 標準の `crypto` で実装しました。依存も秘密情報も増えません。代わりに取り消しの確認はできませんが、トークンの有効期限が1時間なので、今の用途では受け入れています。

- よくある追加の質問：自分で JWT を検証するのは危なくないですか？
  - 答え：危ないのは確かめる項目の漏れなので、公式ドキュメントの項目（`alg`・`kid`・署名・`exp`・`iat`・`aud`・`iss`・`sub`・`auth_time`）を1つずつ実装し、不正なトークン・期限切れ・別プロジェクトのトークンが拒否されることを確かめました
