# ADR-0014：シラバス・口コミを DB に移し、必要な分だけ読む

- 状態：提案（`syllabus-db` の設計で決める）
- 日付：2026-11-06（論点と比較を記録）

## 選択肢

- 今のまま（ADR-0013）
- Firestore にシラバスのコレクションを作る
- RDB（Supabase の Postgres など）
- 大学・年度ごとに分けた静的 JSON を、必要なときに fetch する

## 決めたこと

まだ決めていない（`syllabus-db` の設計で決める）。

## 選んだ理由

（変えたい理由）

このアプリを全国展開させると考えたときにjsonにまとめるやり方だとユーザーがいらない情報までダウンロードしてしまいアプリの最初の読み込みが重くなると考えたからです。

大学が増えると、データの更新のたびにアプリの再デプロイが必要になる。データとアプリのリリースを切り離したい。
